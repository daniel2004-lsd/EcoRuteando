## 🎯 Sobre el Proyecto

<table>
<tr>
<td width="50%" valign="top">

### El Problema

- 🚗 Alta contaminación vehicular urbana
- 🏙️ Congestión en horas pico
- ❓ Falta de conocimiento de rutas seguras para ciclistas
- 📉 Baja adopción de movilidad sostenible

</td>
<td width="50%" valign="top">

### Nuestra Solución

- 🚴 Rutas inteligentes multimodales
- 🌱 Cálculo de impacto ambiental en tiempo real
- 📍 Red colaborativa de reportes ciudadanos
- 📊 Estadísticas personalizadas de contribución

</td>
</tr>
</table>
