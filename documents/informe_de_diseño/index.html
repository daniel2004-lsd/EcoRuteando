Sobre el proyecto

EcoRuteando es una aplicación diseñada para promover una nueva forma de movilidad urbana, donde la tecnología y el cuidado del medio ambiente se integran para ofrecer alternativas de transporte más sostenibles.

Rutas Sostenibles

Combina bicicleta y transporte público para desplazamientos eficientes.

Impacto Ambiental

Calcula el CO₂ evitado al elegir alternativas ecológicas.

La aplicación permite a los ciudadanos descubrir y utilizar rutas sostenibles que combinan diferentes medios de transporte, apoyándose en herramientas digitales intuitivas y fáciles de usar.

Usuarios Objetivo
  • Estudiantes universitarios
  • Trabajadores urbanos
  • Ciclistas urbanos
  • Ciudadanos comprometidos con el medio ambiente

Funcionalidades Principales
Planificación de Rutas

Calcula rutas óptimas considerando múltiples medios de transporte.

Cálculo de CO₂

Estima el impacto ambiental de cada trayecto realizado.

Estadísticas

Visualiza tu historial y contribución ambiental.

El sistema implementa una arquitectura de tres capas que separa la lógica de presentación, negocio y datos.

Capa de Presentación
Frontend / Interfaz Usuario
Capa de Negocio
API / Lógica de Aplicación
Capa de Datos
Base de Datos / Persistencia

  • Módulo de Usuarios: Gestión de perfiles y autenticación
  • Módulo de Rutas: Cálculo y optimización de trayectos
  • Módulo de CO₂: Estimación de emisiones evitadas
  • Módulo de Estadísticas: Visualización de datos históricos
